# 資料表關聯（大總表與分潤表）

依心智圖整理：**中心主題 = Database 大總表**，其餘表透過 **專案ID** 與大總表關聯。

---

## 一、核心關聯圖（文字版）

```
大總表（中心主題）
  │ 專案ID、專案名稱、專案類型、專案狀態、開案日期、KOL名稱、廠商名稱、
  │ 專案總金額(未稅)、專案成本、專案營收、各角色分潤比例(BD+PM 10%、引薦人 2.5% 等)
  │
  ├─ 角色（分潤）  ← 專案ID、專案名稱、專案總金額、角色名稱、分潤%數(由角色設定)
  ├─ 專案          ← 專案ID、專案負責人Email、協辦KOL、專案資料夾、CreatedAt、UpdatedAt
  ├─ 任務          ← 專案ID、任務ID、任務名稱、任務狀態、任務層級；另含 Partner 相關欄位
  ├─ 財務          ← 專案ID、專案實際成本、專案分潤、專案利潤、墊款、廠商/員工付款狀態
  └─ 廠商          ← 發票ID、專案總金額(含稅/未稅)、廠商付款日、實付金額、付款狀態

users（帳號，獨立主檔）
  └─ 與大總表／專案：可透過 專案負責人Email、專案BD 等欄位對應，決定誰看到哪些專案
```

## 三、各表與大總表的關聯

| 表名 | 關聯鍵 | 主要欄位（心智圖） |
|------|--------|---------------------|
| **角色** | 專案ID、專案名稱、專案總金額 | 角色名稱、分潤%數(由角色去設置固定的%數) |
| **專案** | 專案ID | 專案名稱、專案狀態、專案負責人Email、開案日期、專案類型、協辦KOL、專案總金額(未稅)、專案成本、專案資料夾、備註、CreatedAt、UpdatedAt |

| **財務** | 專案ID、專案總金額(未稅)、專案成本 | 專案實際成本、專案分潤、專案利潤、專案利潤比、墊款金額、廠商付款狀態、員工分潤狀態 |
| **廠商** | 專案總金額(含稅/未稅) | 發票ID、發票號碼、發票日期、廠商預計付款日、廠商實付金額、廠商付款狀態、廠商付款日期、備註 |

## 四、關聯一覽（表對表）

| 主表 | 欄位 | 關聯到 | 說明 |
|------|------|--------|------|
| **大總表** | 專案ID | 角色、專案、任務、財務 | 中心鍵，其餘表皆可依專案ID 串回大總表 |
| **大總表** | KOL名稱 | 合作夥伴／KOL 主檔 | 專案所屬 KOL |
| **大總表** | 廠商名稱 | 廠商 | 專案對應廠商 |
| **角色** | 專案ID、專案名稱 | 大總表 | 分潤%數依角色設定，用專案總金額計算 |
| **專案** | 專案ID | 大總表 | 專案主檔／明細，含負責人、協辦KOL、資料夾 |
| **任務** | 專案ID | 大總表 | 專案底下的任務；任務表內含 Partner 欄位 |
| **財務** | 專案ID | 大總表 | 實際成本、分潤、利潤、付款狀態 |
| **廠商** | 專案總金額等 | 大總表 | 發票與廠商付款 |
| **users** | email、name | 大總表／專案.專案負責人Email、專案BD 等 | 決定帳號能看到哪些專案 |

## 五、依角色決定「顯示什麼」的建議鍵

| 角色 | 建議過濾依據 | 關聯路徑 |
|------|--------------|----------|
| 經紀人 | 專案負責人Email／專案BD = 自己；或 KOL 歸自己負責 | users → 大總表(專案負責人、KOL名稱) → 任務、財務、角色(分潤) |
| 董事長／管理 | 不過濾 | 大總表 + 全部關聯表 |
| 內容企劃／其他 | 專案負責人、任務負責人 等 | 大總表 → 專案、任務 |
| 財務 | 依需求看財務表、廠商、分潤狀態 | 大總表 → 財務、廠商、角色 |

**程式設定檔**：`src/config/role-visibility.ts` 定義每個角色可看到的區塊；過濾邏輯依上表與大總表欄位實作。

## 六、Supabase 實際表名與欄位對照（依 docs/0303_1.sql）

Migration 檔：`supabase/migrations/004_schema_0303.sql`。表名與欄位均為中文。

### 表名對照

| 心智圖／說明 | Supabase 表名 | 關聯 |
|--------------|---------------|------|
| 大總表（中心主題） | **大總表** | 主表，`專案ID` UNIQUE |
| 角色（分潤） | **分潤表** | `專案ID` → 大總表(專案ID) |
| 任務 | **任務** | `專案ID` → 大總表(專案ID) |
| 財務 | **財務** | `專案ID` → 大總表(專案ID) |
| 發票／廠商 | **發票** | `專案ID` → 大總表(專案ID) |
| 使用者 | **users** | 已存在，維持 email/password 登入 |

分潤成數：直接寫入大總表（專案BDPM分潤成數、專案引薦人分潤成數、專案管理員分潤成數、執行管理員分潤成數），供分潤表自動建立時帶入。

### 大總表 欄位

專案ID、專案名稱、專案類型、專案狀態、狀態確認日期、開案日期、專案總金額未稅、專案營收、專案成本、KOL費用未稅、KOL名稱、專案費用類型、廠商名稱、專案內容、備註、專案BDPM、專案引薦人、專案管理員、執行管理員、專案資料夾、**專案BDPM分潤成數**、**專案引薦人分潤成數**、**專案管理員分潤成數**、**執行管理員分潤成數**（Migration 006，分潤成數直接寫入大總表）、created_at、updated_at

### 分潤表 欄位

專案ID、專案名稱、專案總金額未稅、角色、分潤成數、分潤金額、**領取人**（對應大總表的 專案BDPM／專案引薦人／專案管理員／執行管理員）

### 任務 欄位

任務ID、專案ID、任務名稱、任務狀態、備註

### 財務 欄位

專案ID、專案總金額未稅、專案成本、專案實際成本、專案分潤、專案利潤、專案利潤比、發票號碼、廠商付款狀態、員工分潤狀態

### 發票 欄位

專案ID、發票號碼、發票日期、專案總金額未稅、專案總金額含稅、專案稅金、廠商預計付款日、廠商實付金額、廠商付款狀態、廠商付款日期、備註

連動規則：子表皆以 `專案ID` 外鍵連到大總表，設有 `ON DELETE CASCADE`。
